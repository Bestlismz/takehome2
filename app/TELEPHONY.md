# เตรียมเชื่อมต่อโทรศัพท์จริง

ขณะนี้แอปยังใช้สายสาธิตในเบราว์เซอร์ ตัวเชื่อม `telephony.py` เตรียมสำหรับทดสอบเสียงเรียกเข้าเบอร์จริงหนึ่งครั้งเท่านั้น เมื่อรับสายจะได้ยินข้อความภาษาไทยที่ระบุว่าเป็น AI และสายทดสอบ แล้ววางสาย ไม่รับเสียงตอบกลับ ไม่ส่งข้อมูลสุขภาพ และไม่บันทึกเสียง

ยังไม่ได้โทรออกจริงในการพัฒนาครั้งนี้ การทดสอบอัตโนมัติใช้ผู้ให้บริการจำลองทั้งหมด

## ตั้งค่าเมื่อมีบัญชีผู้ให้บริการแล้ว

เลือก Twilio เป็นตัวเชื่อมเริ่มต้นเพราะ [Calls API](https://www.twilio.com/docs/voice/api/call-resource) รับคำสั่ง TwiML ในคำขอโดยตรง จึงทดสอบเสียงทักทายได้โดยยังไม่ต้องเปิด webhook สาธารณะ

1. เตรียมบัญชี Twilio และเบอร์โทรออกที่รองรับ Voice ตรวจสิทธิ์โทรไปประเทศปลายทางใน [Dialing permissions](https://www.twilio.com/docs/voice/api/dialing-permissions-resources) ก่อน
2. สำหรับบัญชีทดลอง ตรวจสอบข้อจำกัดและยืนยันเบอร์ผู้รับตาม [Voice trial guide](https://www.twilio.com/docs/usage/trials/try-out-voice)
3. สำหรับปลายทางประเทศไทย ตรวจ [Thailand Voice guidelines](https://www.twilio.com/en-us/guidelines/th/voice) โดยเฉพาะข้อจำกัด caller ID เบอร์ไทยที่ verify เองไม่รองรับการเป็นเบอร์โทรออกไปไทย
4. กรอกค่าจริงเฉพาะใน `.env.local` ที่ Git ไม่ติดตาม ห้ามใส่ใน JavaScript หรือ commit

```dotenv
TWILIO_ACCOUNT_SID=
TWILIO_AUTH_TOKEN=
TWILIO_FROM_NUMBER=
LUKLAAN_TEST_PHONE=
LUKLAAN_ENABLE_TEST_CALLS=0
```

ใช้รูปแบบ E.164 สำหรับเบอร์โทร เช่น รหัสประเทศขึ้นต้นด้วย `+` และไม่ใช้เลขนำหน้าประเทศแบบภายในประเทศ `LUKLAAN_TEST_PHONE` เป็นปลายทางเดียวที่อนุญาต ฝั่งไคลเอนต์เปลี่ยนเบอร์ปลายทางผ่านคำขอไม่ได้ เปลี่ยน flag เป็น `1` เฉพาะเมื่อต้องการเปิดทดสอบ แล้วรีสตาร์ต backend ค่าทั้งหมดต้องครบและถูกต้องจึงจะพร้อมโทร การเรียก API จริงอาจคิดค่าใช้บริการตามบัญชี Twilio

## ขอบเขตตัวเชื่อม

`TelephonyAdapter.status()` คืนเฉพาะสถานะการตั้งค่าและชื่อค่าที่ขาด ไม่คืนเบอร์หรือ credential

`TelephonyAdapter.start_test_call(request_id)` ใช้ UUID ของคำขอเป็น idempotency key สร้างสิทธิ์ทดสอบด้วยไฟล์แบบ exclusive ก่อนติดต่อ Twilio เพื่อกันคำขอพร้อมกัน คำขอเดิมที่สำเร็จแล้วคืนผลเดิมโดยไม่โทรเพิ่ม คำขอใหม่ถูกปฏิเสธหลังใช้สิทธิ์หนึ่งครั้ง ผล `queued` หมายถึง Twilio รับคำขอแล้ว ไม่ใช่หลักฐานว่าโทรศัพท์ดังหรือผู้รับรับสาย

การโทรกำหนดเวลารอสาย 20 วินาทีและระยะเวลาสายสูงสุด 30 วินาที พร้อมปิดการบันทึกเสียงตามพารามิเตอร์ของ [Calls API](https://www.twilio.com/docs/voice/api/call-resource) เสียงทดสอบใช้ `Google.th-TH-Chirp3-HD-Aoede` ตามรายการเสียงและรูปแบบ `Provider.Voice` ของ [Twilio Text-to-Speech](https://www.twilio.com/docs/voice/twiml/say/text-speech) เสียงกลุ่ม Generative ยังเป็น Public Beta

สถานะสิทธิ์อยู่ใน `app/.runtime/telephony-test.json` ไม่เก็บเบอร์หรือ token และอนุญาตอ่านเขียนเฉพาะเจ้าของไฟล์ การรีสตาร์ต process ไม่ล้างสิทธิ์ หากคำขอ timeout ระบบยังถือว่าใช้สิทธิ์แล้วเพราะผู้ให้บริการอาจรับคำขอไปแล้ว ต้องตรวจ Voice logs ใน Twilio Console ก่อนให้ผู้ดูแลเตรียมรอบทดสอบใหม่ ห้าม retry การโทรอัตโนมัติ

สิทธิ์นี้ใช้ร่วมกันเฉพาะ process ที่เห็นไฟล์เดียวกัน หากนำไปรันหลายเครื่องหรือสร้าง container ใหม่ ต้องย้ายสิทธิ์ทดสอบไปฐานข้อมูลร่วมและตั้งขีดจำกัดค่าใช้จ่ายระดับบัญชีก่อนเปิดใช้งานจริง ตัวเชื่อมนี้ยังไม่มี scheduler, status callback, webhook รับสาย, การสนทนา OpenAI ผ่าน PSTN หรือระบบโทรฉุกเฉิน

## ทดสอบโดยไม่โทรจริง

```sh
.venv/bin/python -m unittest discover -s app/tests -p test_telephony.py
```

ชุดทดสอบตรวจการบล็อกเมื่อยังไม่ตั้งค่า ปลายทาง allowlist รูปแบบคำขอ Twilio การไม่คืนข้อมูลส่วนตัว การ replay คำขอ การกันคำขอพร้อมกัน และการไม่ retry เมื่อผลการส่งไม่แน่นอน
