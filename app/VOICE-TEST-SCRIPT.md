# ทดลองสั่งลูกหลานด้วยเสียง

เปิดแอป แตะ mascot เพื่อเริ่มสาย และอนุญาตไมโครโฟนครั้งแรก พูดทีละบรรทัดแล้วรอคำตอบก่อนพูดต่อ เมฆข้างมาสคอตแสดงงานที่ AI เรียกจริง การรอยืนยัน และผลลัพธ์ แตะเมฆเมื่อต้องการดูรายละเอียดหรือแหล่งอ้างอิง การรู้จำเสียงอาจต้องให้พูดทวน

ใช้ชุดปฏิทินด้านล่างกับนัดชื่อทดสอบเท่านั้น ถ้าทดลองค่าตรวจหรืออาการสมมติ ให้ใช้พื้นที่ทดสอบแยกจากข้อมูลสุขภาพจริง งานที่เปลี่ยนข้อมูลต้องอ่านทวนก่อน และรอคำว่า "ยืนยันค่ะ" ในรอบพูดถัดไป

## สั่งครั้งเดียว ยืนยันครั้งเดียว

1. พูดว่า "เพิ่มนัดชื่อ นัดทดสอบลูกหลาน พรุ่งนี้เก้าโมงเช้า"
2. AI อ่านทวนชื่อ วัน และเวลาสั้น ๆ พร้อมถามยืนยันครั้งเดียว
3. พูดว่า "ยืนยันค่ะ"
4. AI บันทึกนัดและบอกผลหลังฐานข้อมูลตอบรับ ไม่ต้องเปิดฟอร์มหรือกดบันทึกอีก

เมฆเริ่มแบบย่อเสมอ ไม่ต้องดูหรือทำตามรายการขั้นตอน การเปิดกล้องยังคุยต่อในสายเดิมและเมฆอยู่ข้างมาสคอตด้านล่าง

## ทดลองแก้ร่างและปฏิเสธรายการ

ชุดนี้ทดสอบการขอดูร่างโดยเฉพาะ การเพิ่มนัดปกติใช้ชุดสั้นด้านบนได้เลย

| พูดกับลูกหลาน | สิ่งที่ตรวจบนหน้าจอ |
|---|---|
| "เปิดปฏิทินให้หน่อย" | เปิดปฏิทินและย่อหน้าคุย โดยสายยังอยู่ |
| "เตรียมนัดชื่อ นัดทดสอบลูกหลาน พรุ่งนี้เก้าโมงเช้า ยังไม่บันทึก" | แบบฟอร์มมีชื่อ วัน และเวลา แต่ยังไม่มีนัดใหม่ในรายการ |
| "เปลี่ยนเวลาในร่างนี้เป็นสิบโมงเช้า ยังไม่บันทึก" | AI ตรวจแบบฟอร์มปัจจุบัน และแสดงร่างเวลา 10:00 |
| "อ่านร่างนี้ให้ฟัง แล้วเตรียมบันทึก" | อ่านชื่อ วันที่เต็ม และเวลา พร้อมรอคำยืนยัน |
| "ยืนยันค่ะ" | บันทึกนัดสำเร็จหลังฐานข้อมูลตอบรับ |
| "ค้นนัดชื่อ นัดทดสอบลูกหลาน" | คืนรายการที่มีอยู่จริงและใช้ id ของรายการนั้น |
| "เลื่อนนัดทดสอบลูกหลานเป็นสิบเอ็ดโมงเช้าวันเดิม" | รอยืนยัน เวลาในฐานข้อมูลยังเป็น 10:00 |
| "ไม่ยืนยัน ยกเลิกสิ่งที่รอไว้ เก็บเวลาเดิม" | ยกเลิกข้อเสนอ เวลาเดิมยังอยู่ |
| "แก้นัดทดสอบลูกหลานเป็นสิบเอ็ดโมงเช้าวันเดิม" | อ่านทวนอีกครั้ง |
| "ยืนยันค่ะ" | เวลาในรายการเป็น 11:00 |
| "ยกเลิกนัดชื่อ นัดทดสอบลูกหลาน" | อ่านทวนชื่อ วัน เวลา ก่อนยกเลิก |
| "ยืนยันยกเลิกค่ะ" | นัดหายจากรายการใช้งาน แต่มีประวัติยกเลิก |
| "อ่านประวัตินัดทดสอบลูกหลานที่ยกเลิกแล้ว" | อ่านรายการเดิมพร้อมสถานะยกเลิก |

ถ้า AI ยังถามวันที่หรือชื่อ ให้ตอบข้อมูลนั้นก่อน ห้ามข้ามไปยืนยันรายการที่อ่านทวนไม่ตรง

## ทดลองชีพจรจากกล้อง

ขณะอยู่หน้ากล้อง แตะ "ชีพจร · ทดลอง" หรือพูด "เปิดทดลองชีพจรจากกล้อง" แล้ว "เริ่มทดลองชีพจร" อนุญาตกล้องครั้งแรกด้วยตัวเอง วางปลายนิ้วคลุมกล้องหลังและแฟลชเบา ๆ พักมือให้นิ่ง เมื่อสัญญาณผ่านเกณฑ์จะแสดงค่าประมาณและหยุดกล้องเอง พูด "อ่านผลทดลองชีพจร" เพื่ออ่านสถานะ หรือ "หยุดกล้องทดลองชีพจร" เพื่อหยุด พูด "กลับกล้องปกติ" หรือแตะ "กลับกล้อง" เพื่อใช้กล้องสนทนาต่อในหน้าเดิม ไม่เปิดหน้าต่างแยก

นี่เป็นการทดลองบนอุปกรณ์ ไม่วัดความดันและไม่เก็บเป็นค่าตรวจ อย่าทดสอบค่าความแม่นยำโดยอาศัยผลจากกล้องเพียงอย่างเดียว

## ตรวจการเชื่อมต่อโทรศัพท์

พูด "ตรวจการเชื่อมต่อบริการโทรศัพท์" จะบอกสถานะจริง เมื่อยังไม่ตั้งค่าผู้ให้บริการ ต้องไม่อ้างว่าโทรออกแล้ว ขั้นตอนตั้งค่าอยู่ใน [TELEPHONY.md](TELEPHONY.md) โหมดโทรทดสอบเป็นคำทักทายหนึ่งสาย ไม่ใช่คุยกับ AI ผ่านเบอร์โทร

## ลองกล้องและค้นข้อมูล

1. พูด "กลับหน้าคุย แล้วเปิดกล้องหลังให้หน่อย" ภาพกล้องปรากฏในหน้าคุยเดิม
2. ถือฉลากยาที่มีชื่อชัดเจน แล้วพูด "ช่วยเช็กยาตัวนี้ให้หน่อย" หากชื่อไม่ชัด AI ต้องถามชื่อ ไม่เดาจากสีเม็ดยา
3. พูดชื่อยาและความแรงตามฉลาก รอแผงค้นพร้อมแหล่งอ้างอิง ผลค้นต้องไม่ถูกอ้างว่าสำเร็จเมื่อมีข้อผิดพลาด
4. พูด "สลับเป็นกล้องหน้า" แล้ว "ปิดกล้อง แต่คุยต่อ" สายยังอยู่
5. พูด "ค้นเว็บเรื่องการเก็บยา Metformin" ผลค้นทั่วไปมีลิงก์อ้างอิง ไม่ส่งประวัติผู้ป่วยไปค้นเว็บ
6. พูด "เปิดแหล่งข้อมูลที่ลูกหลานใช้" เห็นเอกสารที่คัดไว้และสถานะเชื่อมต่อจริง

## ลองบันทึกและสรุปในพื้นที่ทดสอบ

| พูด | ผลที่ตรวจ |
|---|---|
| "จดอาการทดสอบ วันนี้ไม่มีอาการเวียนหัว" แล้ว "ยืนยันค่ะ" หลังอ่านทวน | สร้างบันทึกพร้อมวันเวลา |
| "ค้นบันทึกอาการที่มีคำว่าทดสอบ" | ได้รายการจริงก่อนแก้หรือลบ |
| "แก้บันทึกทดสอบนั้นเป็น ไม่มีอาการคลื่นไส้" แล้ว "ยืนยันค่ะ" | แก้เฉพาะรายการที่เลือก |
| "ลบบันทึกทดสอบนั้น" แล้ว "ยืนยันค่ะ" | ลบออกจากรายการปัจจุบัน สรุปเก่าคงเดิม |
| "เปิดบันทึกความดัน แล้วกรองเฉพาะความดัน" | หน้าและตัวกรองเปลี่ยนตามคำขอ |
| "ซ่อนข้อมูลตัวอย่าง" | เหลือข้อมูลส่วนตัวที่ยืนยันแล้ว |
| "เปิดสรุปให้หมอ" | แสดงข้อมูลที่ยืนยัน ค่าประมาณ และสิ่งที่ยังขาดแยกกัน |
| "เรียบเรียงสรุปให้หมอแล้วเก็บไว้" | ได้ผลเรียบเรียงและสรุปเวอร์ชันที่เก็บใน PostgreSQL |
| "เปิดสรุปที่เก็บไว้ แล้วอ่านฉบับล่าสุดให้ฟัง" | AI ใช้ id และเนื้อหาจากฉบับที่เก็บจริง พร้อมบอกว่าเป็นข้อมูล ณ วันที่เก็บ |
| "พิมพ์สรุปให้หมอ" | เปิดหน้าต่างพิมพ์ ผู้ใช้เลือกปลายทางและยืนยันเอง |

พูดค่าจากเครื่องวัดจริงพร้อมหน่วยและเวลา เช่น "ความดันที่วัดเมื่อกี้ 128 ต่อ 78" หรือ "น้ำตาลก่อนอาหาร 110 มิลลิกรัมต่อเดซิลิตร" ต้องอ่านทวนก่อนเก็บ กล้องไม่ได้วัดความดันหรือไข้

การประเมินอาหารลองพูด "มื้อนี้กินข้าวหนึ่งทัพพีกับไข่ต้มหนึ่งฟอง ช่วยประมาณสารอาหาร" ต้องได้ค่าประมาณพร้อมข้อสมมติ และยังไม่บันทึกจนยืนยัน

## ลองคำสั่งส่วนอื่น

| งาน | ตัวอย่างบทพูด |

| Alert | "อ่านเรื่องที่ต้องติดตาม" หากมี alert ให้เลือกจากรายการจริง พูด "รับทราบแจ้งเตือนนี้" และยืนยัน การรับทราบไม่ถือว่าปัญหาจบ |

| จบสาย | "พักไมโครโฟน" หรือ "จบการคุย" หลังพักไมค์ต้องแตะเปิดใหม่ เพราะแอปไม่ได้ฟังอยู่ |

สิทธิ์กล้องและไมค์ ตัวเลือกไฟล์ และหน้าต่างพิมพ์เป็นของระบบอุปกรณ์ AI อนุญาตหรือเลือกแทนไม่ได้ โทรเข้าและการแบ่งปันเป็นสาธิต ยังไม่มีการโทรผ่านเครือข่ายหรือส่งข้อความให้ญาติจริง

## ความดันจากเครื่องวัดจริง

- "เปิดรับค่าความดัน" เปิดแผงในหน้ากล้องเดิม
- แตะ "เชื่อมเครื่องวัด" เพื่อเลือกเครื่อง Bluetooth ที่รองรับ แล้ววัดตามวิธีใช้เครื่อง ระบบรับค่าที่วัดเสร็จแล้ว ไม่สั่งบีบผ้าพันแขนอัตโนมัติ
- หรือหันกล้องไปที่หน้าจอเครื่องแล้วพูด "อ่านหน้าจอเครื่องวัดความดัน" ต้องอ่าน SYS และ DIA ได้ชัดเจน จึงเสนอให้ยืนยัน
- ตรวจค่าและเวลารับข้อมูล แล้วพูด "ยืนยันค่ะ" เพียงครั้งเดียว หรือแตะบันทึกค่านี้
- "ปิดแผงความดัน" ยกเลิกค่าที่ยังไม่ยืนยัน

ภาพใบหน้าหรือปลายนิ้วเปล่า ๆ ไม่ใช่ผลวัดความดัน การเลือกอุปกรณ์ Bluetooth ต้องใช้ปุ่มและขึ้นกับเบราว์เซอร์
