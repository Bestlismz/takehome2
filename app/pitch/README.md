# ลูกหลาน HTML pitch

เปิด `http://localhost:5173/pitch/index.html` เมื่อรัน app server อยู่ เป็นสไลด์ภาษาไทยสำหรับกรรมการและนักลงทุน 11 หน้า

- ลูกศรซ้าย/ขวา หรือปุ่มด้านล่างเปลี่ยนสไลด์
- `F` เปิดเต็มหน้าจอ, `N` เปิดบทพูด, `Home`/`End` ไปหน้าแรก/สุดท้าย
- โทรศัพท์จำลองกดคุย ยืนยันบันทึก เปิดกล้อง เพิ่มนัด สลับสรุป และรับสายตัวอย่างได้
- เดโมเป็นสถานะชั่วคราวในหน้า ไม่มีการเรียก OpenAI เปิดกล้อง โทรจริง หรือเขียนข้อมูลสุขภาพ
- ตัวเลขตลาดอ้างอิง NSO ปี2567 ส่วนรายได้และช่องทางเป็นสมมติฐาน แยกจากฟีเจอร์ปัจจุบันและงานก่อนใช้งานจริง
- ใช้ภาพมาสคอตจาก `app/assets/` และฟอนต์ IBM Plex Sans Thai จาก Google Fonts มี sans-serif สำรอง

ออกแบบตามโทนครีม น้ำเงิน และมาสคอตเดิมจากแอป โดยใช้หน้าจอ HTML จำลองเพื่อไม่แสดงข้อมูลสุขภาพจริงระหว่างขาย
