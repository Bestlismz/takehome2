# เริ่มคุยง่าย และดูบันทึกของตัวเองได้ชัด

วันที่ 4 พฤศจิกายน 2569 ผู้ใช้ขอให้ UX/UI ใช้ง่ายขึ้น และระบุให้เอาฟองตั้งใจฟัง ป้ายภาพสด และข้อความแนะนำด้านล่างออกเมื่อเปิดกล้อง

## สิ่งที่พบจากหน้าที่เปิดตรวจ

หน้าหลักมีหัวเรื่องใหญ่ก่อนการ์ดเริ่มคุย มีปุ่มสั่งงานซ้ำหลายจุด และข้อมูลตัวอย่างปนในค่าล่าสุด หน้าประวัติใช้ปุ่มประเภทเก้าปุ่มและแสดงรายการตัวอย่างพร้อมบันทึกจริง กล้องมีสถานะสามชิ้นทับบริเวณภาพ ขณะตรวจมีสายกล้องจริงเปิดอยู่ จึงไม่รีโหลดหรือตัดสายนั้น

## ปรับแล้ว

- เก็บ mascot และโทนกระดาษ ดินเผา กับน้ำเงินเดิม เปลี่ยนลำดับหน้า ไม่สร้างภาพตัวละครใหม่
- หน้าหลักยกการคุยเป็นปุ่มหลัก มีทางลัดนัดหมาย/บันทึกเพียงสองรายการ นัดวันนี้แสดงจากนัดที่บันทึกจริง ส่วนเครื่องมือจดอาหารและลองโทรยังเข้าถึงได้ในส่วนขยาย
- ค่าล่าสุดใช้บันทึกที่ไม่ใช่ตัวอย่างเท่านั้น และมีวันที่กับเวลา ไม่ตีความค่าของเมื่อวานเป็นค่าของวันนี้
- สมุดสุขภาพใช้ช่องค้นหาและ select ประเภท แบ่งกลุ่มตามวันประเทศไทย แสดงบันทึกของผู้ใช้ก่อน มี opt-in สำหรับตัวอย่าง ถ้าค้นไม่พบมีปุ่มล้างการค้นหา การค้นไม่เปลี่ยนฐานข้อมูลและไม่ย้าย focus ออกจากช่องกรอก
- ปุ่มแก้ไขมีชื่อและพื้นที่กดชัดเจน เปิดค่าจริงของรายการเดิม ไม่ซ่อนความสามารถแก้ไข
- history.filter รองรับ text และ enabled เพื่อสั่งค้น/เปิดปิดข้อมูลตัวอย่างด้วยเสียงได้ โดยเป็นการเปลี่ยนมุมมอง ไม่มีการเขียนบันทึกสุขภาพ
- ปิดกล้องแล้วกลับไปเห็นสถานะคุยตามเดิม เมื่อภาพกล้อง live ฟองสถานะและ badge ไม่แสดง ส่วนข้อความ live status คงไว้ให้ screen reader แต่ไม่ทับภาพ ข้อความเรื่องการส่งเสียง/ภาพอยู่ในหัวหน้าคุย
- เพิ่มสไตล์ขยายตัวอักษรสำหรับส่วนใหม่ และลด motion ตามการตั้งค่าระบบ

## ตรวจใช้งาน

Browser บน localhost กับข้อมูลเดิมตรวจแล้วว่าประวัติเริ่มจากสามบันทึกจริง เปิดตัวอย่างเป็นสิบเอ็ดรายการ กรองความดันเหลือสองรายการ ค้นค่า 129 เหลือรายการที่ตรง ค้นไม่พบแล้วกดล้างได้ ปุ่มแก้ไขเปิด 129/80 ของรายการที่เลือก ก่อนปิดหน้าต่างโดยไม่บันทึกใหม่

ตรวจ desktop 1280px กับมือถือ 390px และ 320px ไม่พบ horizontal overflow ในหน้าที่ตรวจ ปุ่มเริ่มคุยอยู่ใน viewport แรกบนมือถือ ทดสอบ layout กล้องผ่าน camera-preview.html ซึ่งใช้ component และ CSS เดียวกัน แต่ไม่เปิดกล้อง ไมค์ หรือส่งข้อมูลจริง ตรวจ computed styles ของฟองและ badge เป็น display:none และ caption ถูก clip อยู่ในพื้นที่ 1px; ปิด/เปิดตัวอย่างแล้วสถานะกลับมาตามโหมด

JavaScript 74 และ Python 39 tests ผ่าน รวม 113 รายการ มีสามกรณีใหม่สำหรับแยกตัวอย่าง ค้นและกรอง และจัดกลุ่มวันประเทศไทย อีกหนึ่งกรณีสำหรับคำสั่งเสียงค้นสมุดสุขภาพ git diff --check ผ่าน

การตรวจ layout ไม่ใช่การรับรอง accessibility หรือ usability กับผู้สูงอายุจริงทุกกรณี ไม่ได้บันทึกภาพจากสายจริงของผู้ใช้ ระหว่างพัฒนาคงสายเดิมไว้ ส่วน UI ที่โหลดก่อนแก้ต้องรีเฟรชหลังจบสายเพื่อรับ CSS/JS ใหม่
