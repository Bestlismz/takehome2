# เช็กยาจากฉลากแล้วค้นเว็บ

ผู้ใช้รายงานวันที่ 4 พฤศจิกายน 2569 ว่าพูดว่า “ช่วย check ยาตัวนี้ให้หน่อย” แล้วค้นเว็บไม่ได้

## ปัญหาที่ทำซ้ำได้

1. คำค้นสาธารณะ “ชื่อยา metformin 500 mg” และ “ยาเมทฟอร์มิน 500 มิลลิกรัม” ถูกตัวกรองข้อมูลส่วนตัวปฏิเสธ ทดสอบก่อนแก้ล้มเหลวสามกรณี แก้ให้คำว่า “ชื่อยา” และความแรงบนฉลากค้นได้ ยังปฏิเสธชื่อผู้ป่วย ข้อมูลติดต่อและค่าตรวจส่วนตัวตามรูปแบบที่ตรวจพบ
2. ค้นคำเดิมจาก UI ได้ HTTP 500 จริง บันทึกเฉพาะชนิด exception กับตำแหน่งโค้ดพบ TypeError ใน consulted.extend เมื่อ OpenAI เปิดหน้าเว็บแล้วส่ง action.sources เป็น null แก้การอ่านช่อง optional โดยยังต้องมี search ที่สำเร็จและแหล่งอ้างอิงก่อนแสดงผล มี regression test ที่ล้มเหลวก่อนแก้และผ่านหลังแก้
3. ตัวรับ Realtime ส่ง response.create ทั้งที่ response เดิมยัง active กรณีเครื่องมือเสร็จเร็วถูก provider ปฏิเสธ แก้ให้รอ response.done และรอเครื่องมือในชุดเดียวกันเสร็จก่อนขอคำตอบต่อ
4. ทดสอบเสียงสังเคราะห์แล้วพบ response incomplete เหตุ max_output_tokens ที่เพดาน 1100 ปรับเป็น 2048 พร้อมกำหนดให้สรุปข้อมูลยาเพียงสองประโยค ทดสอบซ้ำได้ response เสียง completed

## พฤติกรรมที่แก้

เพิ่ม medication_lookup รับเฉพาะ name, strength, topic ที่จำกัดรายการ เรียกค้นเว็บจริงโดยเน้นข้อมูลกำกับยาจาก อย., MedlinePlus และ DailyMed ไม่ส่งภาพฉลากทั้งใบ ชื่อคนไข้ หรือบันทึกครอบครัวไปค้น ไม่เปลี่ยนแผนยา

เมื่อยังไม่ทราบชื่อยา ให้ช่วยดูฉลากหรือขอให้ผู้ใช้อ่านชื่อ ไม่เดาจากรูปร่างเม็ด ถ้าเปิดกล้องตามคำขอแล้ว ให้ส่งภาพแรกที่พร้อมให้ Realtime ก่อนขอคำตอบต่อ และขยายหน้าคุยเดิมเมื่อกำลังย่อสายอยู่

การพูดรับสั้น ๆ ระหว่างรอค้นไม่ทำให้ทิ้งผลค้นเพียงเพราะเลขรอบพูดเปลี่ยน แต่สายที่จบแล้วหรือมีคำค้นใหม่แทนจะไม่รับผลเก่ามาตอบ

แหล่งอ้างอิงที่ใช้กำหนดแนวทางค้น ได้แก่ [ข้อมูลยาของ อย.](https://ndi.fda.moph.go.th/drug_info/index) และ [MedlinePlus Drug Information](https://medlineplus.gov/druginformation.html) การพบชื่อยาในเอกสารไม่ได้รับรองความแท้ของเม็ดที่ถือหรือความเหมาะสมต่อบุคคล

## ตรวจแล้ว

- JavaScript 68 และ Python 39 รายการผ่าน รวม 107 รายการ
- Realtime จริงกับข้อความที่ไม่มีชื่อยาเลือก camera_open กล้องหลัง
- Realtime จริงกับข้อความชื่อ Metformin 500 มิลลิกรัมเลือก medication_lookup ได้แหล่งอ้างอิงและคำตอบต่อ
- เสียงไทยสังเคราะห์ผ่าน OpenAI TTS → Realtime audio input → medication_lookup → ค้นเว็บจริง → Realtime audio reply ได้ completed หลังแก้เพดานคำตอบ ไม่ได้อัดเสียงไมโครโฟนหรือส่งข้อมูลผู้ป่วยจริง
- คำค้นที่เคย 500 ใน browser ได้ผล MedlinePlus หลังแก้ ตรวจสถานะ success และลิงก์จาก UI
- git diff --check ผ่าน

สั่งทดสอบบริการจริงแบบ opt-in ได้ด้วย `.venv/bin/python app/scripts/verify_medication_search.py --audio` ใช้ key ฝั่ง backend ที่ตั้งค่าอยู่และมีค่า API usage สร้างเสียงตัวอย่างในหน่วยความจำ ไม่บันทึกเสียงหรือคีย์ในรายงาน

การทดสอบนี้ไม่ใช่การรับรองความแม่นยำในการอ่านฉลากจากกล้องโทรศัพท์จริงหรือสำเนียงผู้ใช้จริง ต้องให้เห็นชื่อยาได้ชัดและขอทวนเมื่อไม่แน่ใจ
