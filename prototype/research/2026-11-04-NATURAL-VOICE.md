# ภาษาพูดของลูกหลาน

ผู้ใช้ต้องการให้คำตอบฟังเป็นธรรมชาติกว่าเดิม จึงปรับการวางประโยค การทัก การอ่านบทโทรเตือน และจังหวะรับรอบพูด วันที่ 4 พฤศจิกายน 2569

ใช้เสียง Marin เดิมเพื่อแยกการปรับวิธีพูดออกจากการเปลี่ยนผู้พูด ไม่เร่ง playback หรือปรับ pitch เพื่ออ้างว่าธรรมชาติขึ้น แนวทาง OpenAI แยก speaking style ออกจาก audio speed และแนะนำให้ลดการใช้ตัวอย่างซ้ำจนเป็นบทท่อง [Personality and tone](https://developers.openai.com/api/docs/guides/voice-prompting#personality-and-tone)

## เปลี่ยนอะไร

- voice_style.py เป็นแหล่งเดียวสำหรับบุคลิกการคุย เสียงทัก และการอ่านถ้อยคำที่ต้องตรง เช่น ตัวเลขกับคำยืนยัน ใช้ภาษาพูดไทย แทนตัวว่าหนูโดยยังแนะนำว่าเป็นผู้ช่วย AI
- คำตอบทั่วไปมุ่งพูดทีละเรื่อง ไม่ยื่นเมนูกิจกรรมหลายอย่าง ไม่บังคับถามต่อทุกคำตอบ ไม่ใช้คำปลอบหรือคำเปรียบเปรยสำเร็จรูป ไม่แต่งประสบการณ์ส่วนตัวของ AI
- คำสั่งการอ่านบทคงตัวเลข หน่วย เวลา และคำถามยืนยันทุกคำ แต่ให้พูดเป็นวลีในจังหวะโทรศัพท์ แทนคำสั่งให้อ่านตามตัวอักษร
- API เริ่มสายส่ง greetingInstructions และ fixedSpeechDelivery ให้ browser ใช้ จึงไม่ต้องมีบททักที่แข็งกระด้างอีกฉบับใน frontend
- บทโทรสาธิตและคำถามจากปุ่มอาหาร/น้ำตาลใช้สำนวนเดียวกัน การยืนยันข้อมูลและขอบเขตยาเดิมยังคงอยู่
- speaker และ headset เปลี่ยน semantic VAD eagerness จาก low เป็น medium เพื่อไม่รอนานเกินไป ส่วน noisy คงเงื่อนไขรับเสียงเดิม ผู้ใช้ยังพูดแทรกได้ ต้องทดสอบกับผู้สูงอายุที่หยุดคิดกลางประโยคด้วย

## ตรวจแล้ว

สร้างตัวอย่าง Realtime จริงทั้งก่อนและหลังแก้ อ่าน transcript เทียบกันพบว่าคำตอบอิสระยังมีความแปรผัน และไม่ยืนยันว่าทุกคำตอบเป็นธรรมชาติจากการแก้ prompt เพียงอย่างเดียว ตัวอย่างที่ยาวหรือแต่งประสบการณ์ AI ถูกใช้ปรับคำสั่งเพิ่ม ไม่ใช้เป็นหลักฐานผ่านด้านคุณภาพ

ตัวอย่างเสียงทักสุดท้ายจาก Realtime completed และ transcript ตรงกับบททักใหม่ “สวัสดีค่ะ หนูเป็นผู้ช่วยลูกหลานนะคะ วันนี้เป็นยังไงบ้าง” เก็บไฟล์ luklaan-greeting-new.wav ใน visualizations ของแชต ไม่มีการอัดไมโครโฟนผู้ใช้ ไม่มีข้อมูลสุขภาพจริงในเสียงตัวอย่าง

JavaScript 70 และ Python 39 รายการผ่าน รวม 109 รายการ มี contract tests ว่า frontend ใช้บททักที่ server ส่งมา และยังรักษาตัวเลข/เวลา/คำยืนยันเมื่ออ่านด้วยรูปแบบเสียงใหม่ ไม่ตีความจำนวน tests เป็นคะแนนความเป็นธรรมชาติ

CLI ทดสอบตัวอย่างเสียงแบบ opt-in คือ `.venv/bin/python prototype/scripts/preview_voice.py --output /absolute/path/sample.wav` ใช้ OpenAI API จริงและมี API usage เพิ่ม `--sample conversation` เพื่อสร้างตัวอย่างคุยเล่นจากข้อความสมมติ

ยังไม่ได้ทำ listening study กับผู้สูงอายุบนโทรศัพท์จริง จึงต้องให้ผู้ใช้ประเมินจากการคุยจริง การอ่าน transcript อย่างเดียวไม่ตัดสิน prosody สำเนียง หรือจังหวะการพูดทั้งหมด
